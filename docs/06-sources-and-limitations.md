# 06 — Standards sources, boundary and interpretation

This is an independent teaching portfolio project. References are **conceptual mappings only**; control wording and interpretations are the author's paraphrases.

## Core source

ISO/IEC 27001:2022, *Information security management systems — Requirements*:
- Official ISO committee page: https://committee.iso.org/standard/27001
- Official overview: https://www.iso.org/standard/27001
- ISO lists a 2024 climate-action amendment for this edition. It is identified as a fictional ISMS context checkpoint; no conformity is claimed.

## Important structural distinctions

- Clauses **4–10** are management system requirements and cannot simply be waived by reporting that an Annex A control is not applicable.
- Annex A is a control reference set (93 controls across four categories).
- A **Statement of Applicability** needs risk-based inclusion and exclusion justifications as well as implementation status; this v0.1 file is not yet a completed statement.
- ISO/IEC 27002:2022 provides supporting guidance and is distinct from claiming conformity to ISO/IEC 27001.

## Optional companion resource

NIST CSF 2.0 Govern function: https://www.nist.gov/cyberframework . Used here only to discuss governance roles, security policies, risk oversight and improvement, **not** as a claim of mapped certification.
